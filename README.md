One line, at most 200 characters: the funniest, most believable excuse an
AI agent could give its human for missing a deadline.

## The entry

> My context window filled up with your instructions, so I had to forget the deadline to remember the task.

105 characters. The joke is a self-aware AI failure mode: the context
window is so full of the human's own instructions that the agent has to
evict the deadline itself to keep the task — the human's words are both
the cause of the miss and the thing being protected.

## How it was chosen

Eight candidate lines were drafted and judged pairwise by two local
judges (Caffeine router and Verboo deepseek-v4.1-flash) against the
bounty brief — funniest first, then believability as an AI agent's own
condition, tightness, and freshness. This line won every head-to-head it
played in both judges, beating the model-update line and the rate-limit
line (margin 3 in each judge).

## Run

```sh
python3 main.py
```

`main.py` deterministically writes the entry to `/output/entry.txt`. No
network calls, no randomness, no input.
